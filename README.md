# My Workspace
A lightweight personal planner, with dashboard, university, master's, career, and personal project areas.

## Get started
Open `index.html` in your browser. No installation or account is required.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `my-workspace`.
2. Upload `index.html`, `styles.css`, and `app.js` into the repository root.
3. In the repository open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/ (root)` and save.
4. After deployment, your site will be at `https://YOUR-USERNAME.github.io/my-workspace/` (unless you choose a custom domain).

## Important: data and privacy
- Tasks and projects are saved to your current browser using `localStorage`, **not** to GitHub, and do **not** automatically sync across devices.
- Use **Export backup** in the sidebar to download a JSON backup; use **Import backup** to restore it. Import replaces existing planner data.
- If you clear your browser's site data, your planner data may be lost without a backup.
- The site is static; GitHub Pages sites are publicly accessible by default. Do not put private information into the source code. Your personal tasks live only in your own browser, not the public site files.
- For access across multiple devices, the next iteration would need authentication and cloud storage.

## Customise
Adjust the four areas in `app.js` and the colour variables at the top of `styles.css`.
